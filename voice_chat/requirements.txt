# misaki loads spaCy's en_core_web_sm at startup and, if it is missing, shells
# out to `spacy download` -- which fails under systemd in a uv-built venv,
# because that venv has no pip and spaCy looks for one ("No package installer
# found"). Pinning the model as an ordinary wheel is the fix and the better
# property regardless: a service should not be downloading anything on start.
# Keep the version in step with spacy's minor (3.8.x model for spacy 3.8.x).
en_core_web_sm @ https://github.com/explosion/spacy-models/releases/download/en_core_web_sm-3.8.0/en_core_web_sm-3.8.0-py3-none-any.whl
