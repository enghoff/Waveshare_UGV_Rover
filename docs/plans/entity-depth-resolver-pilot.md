# Fixed depth abstention through complete recorded drives

R-WS-13 remains open; R-WS-17 and R-WS-18 remain proposed. This offline
development pilot follows the passed distance test. No production change is
authorised by its scores alone.

Freeze before computing: use all observations in the three archived October 1/2
taped drives, the current committed resolver, one resolver pass per recorded
inspection and the saved October 2 map. Repeat the original-range control and
compare it with recorded memberships and placements. If it differs, report the
schedule/build mismatch; do not call the replay an exact live reproduction.

Run original ranges, reconstructed production-outline ranges, then those same
outline ranges with only the fixed minority-band flags withheld. Reconstruct
every available depth frame, without using target labels to select observations.
Original missing ranges (including turning exclusions) stay missing. Missing
photos, masks with box overlap below 0.5 and unavailable depth stay unchanged.
Do not choose a farther surface. Keep original photos, vectors, observations,
bearing measurements and input databases unchanged. Record every substitution.

The original historical target-to-entity mapping is a proxy label, not independently
reviewed identity truth. Report target-pair connections, wrong cross-target pairs,
waiting, fragments and each target's majority-supported placement against tape.
Report all entities and placement changes, including those outside the labels.
Never score unassigned observations as a shared identity. Entity ID equality
across runs is not identity equality; compare memberships.

Numerical development criteria, fixed now: retain at least 98% of the outline
control's same-target pairs, add no cross-target pairs, and lose no more than 10%
of the control's assigned observations for any target. A placement-benefit claim
also requires median target horizontal error to improve by at least 0.10 m and
no target majority placement to deteriorate by more than 0.25 m. Loss of a target
placement fails that claim. Report each drive separately and pooled counts.
Unchanged scores are inconclusive, not a failed range flag or a proved entity fix.
No tuning or new thresholds follows these measurements in this pilot.

Repeat original and outline controls to verify deterministic memberships and
placements. Record source/model/input hashes. Full schedule provenance, measured
glass/narrow objects and independent labels remain necessary before acceptance.
