# Isolate the cost of limiting model updates

This is explanatory development work for R-WS-13, R-WS-17 and R-WS-18, following
the first tentative-evidence candidate. It is not a replacement acceptance rule.
That candidate's fresh replay removes the clear painting/table error but loses
too much confirmed support and fragments an armchair. No thresholds will be tuned
using that outcome.

On the reproduced fresh recording, compare two deliberately extreme controls:
hold existing appearance fixed while still refitting position, and hold both
existing appearance and position fixed. New discovery founders keep their ordinary
initial models in both arms. Keep all ordinary associations, gates, schedules and
measurements. No labels select which update to withhold. This is a diagnostic of
feedback, not a deployable way for a model to learn novel viewpoints.

Compare wrong and correct relations, waiting and per-object fragmentation with
the unchanged baseline and the two-witness candidate. These controls answer whether
the candidate's cost comes from suppressing updates in general or from how it
chooses evidence and promotes it. A favourable frozen model is not proof that it
will adapt on a new drive or survive bad founders. Interpret all labels as frozen
development judgments, with uncertain fresh labels separately reported.
